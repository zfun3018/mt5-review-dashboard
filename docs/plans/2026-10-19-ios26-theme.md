# iOS 26 Theme Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Replace the existing Morning Mist visual theme with a complete iOS 26-inspired light theme while preserving the Night Sail theme, theme preference compatibility, and current runtime architecture.

**Architecture:** Keep the existing `morning-mist` theme id so saved local preferences remain valid, but change its display name to `iOS 26` and replace its visual tokens. Add a small shared theme stylesheet layer after page styles for material, control, navigation, table, modal, and mobile overrides. Use CSS variables and progressive enhancement only; do not add a framework, runtime animation loop, network request, or backend change.

**Tech Stack:** Native HTML, CSS custom properties, ES modules, Node built-in test runner, existing Lucide icons.
