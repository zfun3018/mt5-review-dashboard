# MT5 复盘系统版本路线

## v0.1.0 基线

- 本地 MT5 EA 桥接、SQLite 存储和原生仪表盘。
- 订单流水、截图、复盘文本、自定义字段、月度日历和盘面统计。
- 作为改造前可运行原型基线。

## v0.2.0 功能版本

- 统一净盈亏：利润、手续费、隔夜利息和费用进入统计口径。
- 增加今日、本周、本月、本年指标卡。
- 增加 3/7/30 天资金曲线选择、日期范围分析 API。
- 增加按日交易系统评估与 Z 分数。
- 增加交易类型、交易策略和模式评估。
- 增加订单服务端筛选、分页、软删除和恢复。
- JSONL 增量读取、规范化事件去重、同步游标、SQLite WAL 和查询索引。
- 真实数据库已完成 schema v2 迁移，迁移前快照保存在 `mt5-review-system/backups/`。

## v0.2.1 界面补丁版本

- 修复四周期指标卡右侧空白，改为四列自适应布局。
- 将分析时间范围筛选移动到收益曲线、系统评估和模式评估上方。
- 增加本日、本周、本月系统评估摘要卡，包含回报、笔数、盈亏比、胜率、盈利/亏损金额和笔数。
- 增加默认展开的 Z 分数解释说明，评估表取消不必要的横向滚动。
- 将资金曲线改为收益累计曲线，左轴显示回报金额，右轴显示收益率。
- 统一分析筛选器、图表图例和评估模块的控件样式，并完成桌面/移动端回归检查。

## v0.2.2 曲线与分析补丁版本

- 收益累计曲线按分析范围的北京时间起止日期过滤，不再混入范围外资金快照。
- 调整曲线模块高度和主体占比，使用响应式画布、清晰双轴文字和曲线点采样。
- 收益金额与收益率曲线使用平滑路径，并保留零回报基准线和区间回报提示。
- 本日、本周、本月系统评估摘要卡增加 Z 分数及结果分类。
- 修复周期摘要基准日被筛选范围之后的资金快照推进，确保单日筛选统计一致。
- 完成后端、前端静态测试，以及桌面端和 390px 移动端页面回归检查。

## v0.2.3 截图同步补丁版本

- 修复 MT5 交易事件先到、K 线截图文件后到时的截图丢失问题。
- 重复事件会重新尝试复制截图，已推进 JSONL 游标的历史交易也会执行缺失截图补偿扫描。
- 已补齐当前数据库中最近两笔交易的截图，并验证 `/media` 返回有效 PNG。
- 新增迟到截图和游标已推进两种场景的回归测试。

## v0.2.4 曲线布局补丁版本

- 累计回报曲线改为按未删除交易的北京时间平仓顺序重建，已删除订单不再污染曲线。
- 资金快照仅用于确定收益率基准资金，不再直接作为累计回报序列。
- 曲线面板独占 Grid 行，月度日历移到下一行，消除月历拉高曲线行造成的大面积空白。
- 重新规划 SVG 两侧坐标轴保留空间，修复金额标签裁切，并提高坐标轴与时间标签对比度。
- 新增软删除交易曲线重建、交易累计回报和前端布局可读性回归测试。

## v0.3.0 当前功能版本

- 新增 schema v3 交易分类配置模型，交易类型与交易策略支持新增、改名和停用。
- 订单使用稳定分类标识：改名只改变显示名称，统计分组、筛选和历史数据保持不变。
- 删除分类改为停用，旧订单仍可显示该分类并参与交易模式评估，新订单不再提供该选项。
- 自动迁移已有交易类型/策略值，并兼容 MT5 后续导入的旧默认值和未知分类值。
- 交易分类筛选器、复盘编辑器和交易模式评估统一读取分类配置，移除前端硬编码选项。
- 自定义字段列宽扩大为约 8 个汉字，复盘编辑区扩大到至少 320px 高并支持 500 字以上文本。
- 备注从订单流水界面和保存流程移除，旧数据库备注数据不做破坏性删除。
- 真实数据库已完成 schema v3 迁移，迁移前快照保存在 `mt5-review-system/backups/mt5-review-backup-20260821-135954.zip`。

## v0.3.1 当前截图补丁版本

- 订单详情增加截图替换和删除操作，支持本地上传、直接粘贴和拖拽图片。
- 替换先写入新截图，再更新订单路径；旧截图仅在没有其他订单引用时自动删除。
- 删除会清空订单截图路径，并同步清理原始交易快照中的截图路径，避免数据库残留旧引用。
- 增加图片格式、15MB 大小限制和路径安全校验；共享截图不会被误删。
- 新增后端截图生命周期测试和前端截图操作静态测试。

## v0.4.0 复盘画册版本

- 新增独立“复盘画册”页面，以现有交易截图为主体，按北京时间平仓日期分组和排序。
- 直接复用当前 SQLite 的 `trades`、分类选项、自定义字段选项、交易自定义值和截图路径，不新增画册数据表，不复制图片，不做历史数据重处理。
- 顶部只提供品种、时间范围和标签筛选；标签来自交易类型、交易策略及单选/多选自定义字段选项。
- 不提供多空筛选，不提供文本型自定义字段筛选，不提供全文搜索；多空和文本字段只在卡片中展示。
- 同一标签维度内多选使用 OR，不同维度之间使用 AND；已删除订单排除，缺失截图订单保留并提供补图入口。
- 桌面端采用左图右信息、移动端图上信息下布局，保留原图比例并支持懒加载和大图预览。
- 新增后端契约测试、画册查询测试和前端静态测试；真实数据库验证当前 48 笔有效订单均可返回。
- 详细实施方案见 `docs/plans/2026-08-23-review-album-design.md`。

## v0.4.1 画册体验补丁版本

- 复盘内容按长度和换行数量自适应：短内容直接展开，可能撑高卡片的长内容才折叠。
- 统一画册筛选栏与仪表盘的深色控件、边框和强调色，修复原生白色输入/选择控件造成的视觉割裂。
- 仪表盘与画册新增共用顶部导航，明确仪表盘首页和画册页面，为后续页面扩展预留导航结构。
- 补充桌面端、390px 移动端无横向溢出和导航状态回归检查。

## v0.4.2 画册阅读补丁版本

- 长复盘默认展开，仍可通过标题手动收起，避免进入画册后整段内容不可见。
- 取消右栏复盘文本的固定八行窗口，让复盘区填充截图旁的剩余高度并在超长时独立滚动。
- 桌面端扩大右侧信息列比例，移动端继续使用图上信息下的单列布局。
- 增加长复盘默认展开、右栏空间分配和移动端断点的前端回归断言。

## v0.4.3 画册滚动补丁版本

- 复盘内容统一渲染为普通可滚动区，避免 `<details>` 内部布局导致段落高度失控。
- 右栏和复盘段落明确设置可收缩边界，长文本始终显示纵向滚动条并不会被底部操作区遮挡。
- 增加 Chrome 桌面端与 390px 移动端 smoke check，覆盖滚动、按钮避让和横向溢出。

## v0.5.0 R 倍数与交易组合版本

- 新增 schema v4 的 `deal_events`、`positions`、`trade_campaigns`、成员关系和分析设置，旧 `trades` 继续作为兼容数据与现金统计来源。
- 对冲账户中，同账户、同品种、同方向且生命周期重叠的 Position 自动组成一个 Campaign；部分平仓和加仓在系统质量统计中只计一笔。
- 每个 Position 单独填写并校验初始止损，Campaign 总计划风险为各 Position 风险之和；任一 Position 缺失、方向无效或成交不闭合时，整个 Campaign R 保持为空。
- Scratch 默认阈值为 `±0.15R` 并可持久化调整；新增净胜率、全样本胜率、R 期望、SQN、R 数据覆盖率和 Campaign 版 Z 分数。
- 现金收益、收益曲线、月历和小时统计继续按退出 Deal 的真实日期；R、SQN、Z 和模式评估按 Campaign 最终平仓日期。
- 订单流水增加 R 缺失高亮和筛选、Position 止损回填与 Deal 明细；系统评估和模式评估显示 Campaign 质量指标。
- 订单流水支持 Scratch 灰显、表格内初始止损编辑、Campaign 汇总/展开，以及加权入场价、出场价和持仓时间展示。
- 所有新增指标共享说明弹层，动态展示公式、Scratch/SQN 阈值、样本量、缺失原因和适用限制，并支持键盘、Escape、点击外部和移动端。
- EA 同步全部 MT5 Deal，同时保留旧平仓事件兼容；历史旧记录幂等重建为 `legacy_estimated` Position，不覆盖既有复盘、分类、自定义字段、截图引用或软删除状态。
- schema v4 首次迁移前使用 SQLite Backup API 在本地 `backups/` 自动创建一次数据库快照，升级成功后不会重复备份。
- 当前 R 只使用价格距离与手数，忽略手续费、利息和其他费用；初始计划风险不代表实际最大浮亏。

## v0.5.1 订单流水体验补丁版本

- 订单流水仅为合并 Campaign 显示展开入口，展开后只展示对应的 Position 子订单。
- 移除全局表格最小宽度和内容裁切规则；桌面端使用紧凑列布局，390px 窄屏使用带字段标签的信息块，避免横向滚动。
- 初始止损直接在订单流水填写；缺失输入显示“请输入初始止损”占位符并高亮，合并 Campaign 展开后逐 Position 编辑。

## v0.5.2 数据恢复与止损输入修复版本

- 读取订单流水前自动重建缺失的 Legacy Deal/Position 关系，避免 Campaign 有笔数但 Position 摘要为空。
- R 状态缺失文案统一为“R 缺失”，不再与初始止损输入框提示重复。
- 加宽桌面端初始止损输入框，确保占位提示和价格可读。

## v0.5.3 组合摘要与子订单数据修复版本

- Campaign 汇总行根据实际 Position 实时计算加权入场价、出场价、总手数和持仓时间。
- 合并 Campaign 展开后的 Position 子行补充该 Position 的盈亏，避免关键结果显示为空。

## v0.5.4 子订单详情与流水布局修复版本

- 订单流水移除复盘文本列，避免长文本导致表格内容溢出。
- 展开的 Position 子订单可独立选中，右侧显示对应来源订单的截图、复盘、自定义字段和成交详情。
- 子订单复盘保存直接写回对应来源订单，Campaign 汇总行继续只承担组合汇总展示。

## v0.5.5 指标命名与说明优化版本

- 指标卡和系统/模式评估不再展示 R 数据覆盖率；覆盖率仅保留为内部数据完整性检查。
- 指标名称改为直白中文：净胜率（剔除打平）、全样本胜率（有效盈利）、平均数学期望（ER）、收益稳定度（SQN）和交易组合数。
- 补充现金 PF、现金胜率和交易组合数的可读说明，明确计算方式与判断标准。

## v0.5.6 指标直观化与评估布局版本

- 移除仪表盘顶部重复指标卡，避免与交易系统评估重复展示。
- 交易系统评估与交易模式评估改为上下排列，减少拥挤。
- 将总盈亏比、总胜率、交易笔数、有效胜率和打平占比等名称改为直白中文，并为指标结果增加好/一般/差/样本不足评价。

## v0.5.7 指标说明与空样本修正版本

- 统一指标说明中的直白名称：总盈亏比、总胜率、交易笔数、有效胜率和打平占比，不再向用户展示现金 PF、现金胜率、Campaign 数和 Scratch 等术语。
- 在指标说明中直接列出好、一般、差和样本不足的判断标准；缺少数据时不再误标为“差”。
- 将交易结果连续性指标的 Z 分数说明改为普通用户可理解的名称。

## v0.5.8 评估维度补充版本

- Z 分数改用与其他指标相同的说明弹层，不再单独占用评估区域。
- 交易系统评估摘要增加本年卡片和净盈亏比；按日统计增加总胜率、净盈亏比、净胜率和打平占比。

## v0.6.0 架构重构版本

- 前端拆分为四个独立工作区：分析仪表盘 `/dashboard/`、订单流水 `/orders/`、复盘画册 `/album/`、设置与系统 `/settings/`，共享统一左侧导航、设计令牌和基础组件。
- 后端重组为数据、领域分析、应用调度、表现四层，依赖只从外层指向内层；表现层不直接执行 SQL，领域层保持纯计算。
- 每个页面只读取自身数据：仪表盘不再加载订单详情或完整 Campaign 列表，图册展示只读 `GET /api/review-album`，复盘保存复用订单复盘接口。
- Campaign 重建从读取路径移到写入或显式修复路径，读取接口不再隐式写数据库；一批 JSONL 导入只在批次末尾重建一次。
- 服务默认只监听 `127.0.0.1`，局域网访问必须显式设置 `MT5_REVIEW_HOST`，旧地址自动重定向到对应新页面。
- 左侧导航提供统一的“刷新数据”操作，执行一次增量同步后刷新当前工作区；系统不会在后台高频轮询。
- 历史 v2/v3/v4 schema 通过幂等迁移升级，迁移前自动创建 SQLite 快照；迁移失败回退旧数据，注入失败演练验证原数据哈希与活跃数不变。
- 运行与数据目录解耦，支持通过环境变量重定向数据/配置根目录而不移动旧数据，为 Windows 桌面封装预留边界。
- 新增 10,000 笔合成订单基准测试、数据兼容/回滚演练、Playwright 桌面与 390px 移动端验证，以及一键发布检查 `tools/check_release.py`。
- 历史订单、截图、复盘、分类、自定义字段、软删除状态和统计口径保持不变，不对历史 JSONL 重新导入或重处理。
- 自定义字段支持停用、恢复和永久删除；永久删除会通过外键级联清除该字段的选项与历史填写内容，并要求前端二次确认。

## v0.6.1 数据刷新与维护补丁版本

- 自定义字段支持停用、恢复和永久删除，补齐设置页说明与迁移手册中的通用示例。

## v0.6.3 订单字段顺序补丁版本

## v0.6.4 订单选中态补丁版本

- 提高订单列表选中行的背景和边框对比度，并为打平订单保留独立的选中配色。

## v0.6.6 订单分类筛选修复版本

## v0.6.7 组合分类口径修复版本

- 订单筛选、列表汇总行和仪表盘模式评估统一读取组合分类，修复筛选“突破”仍出现“窄通道”的口径错位。
- 新 Campaign 初次生成时继承来源分类；创建后重建始终保留自身分类，并提升模型版本执行兼容修复。

## v0.6.8 复盘画册编辑补丁版本

- 复盘画册复用订单列表的复盘编辑器，支持直接修改并保存订单复盘内容。
- 保存沿用现有 `PATCH /api/trades/{id}/review` 接口，不新增数据表或后端架构层。
- 保持桌面端右栏和 390px 移动端布局，长复盘文本在编辑器内独立滚动。

## v0.6.9 复盘保存一致性修复版本

## v0.6.10 订单复盘跳转修复版本

## 工作方式

- 版本格式采用 SemVer：`MAJOR.MINOR.PATCH`。
- `v0.2.x` 只接受统计口径、同步可靠性和界面回归修复。
- `v0.4.x` 只接受画册体验、筛选和图片加载的兼容性补丁。
- `v0.5.x` 只接受 Campaign 重建、R 口径和迁移兼容性修复。
- `v0.6.x` 只接受四层边界、页面所有权、路径解耦、数据兼容和浏览器验收的修复。
- Git 元数据目录当前受运行环境权限限制，代码版本先通过 `VERSION`、本文件和独立迁移快照追踪；权限恢复后应补建 `v0.1.0` 与 `v0.2.0` 标签。
